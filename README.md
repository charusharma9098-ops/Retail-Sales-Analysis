# Retail Sales Analysis

## Project Overview

This project is a **Retail Sales Analysis** built using **SQL and Power BI**.

I used a **drill-down approach** to first look at overall monthly business performance and then explore different areas such as **revenue, profit, customers, products, and regions** in more detail.

The purpose of the project is to analyze sales performance over time and understand how different business metrics change across months and different areas of the business.

---

## Tools Used

* **SQL** – Data analysis and drill-down queries
* **Power BI** – Dashboard and data visualization
* **GitHub** – Project and file management

---

## Dataset

The project uses the `Retail_Sales_Analysis_Dataset.csv` dataset.

The dataset contains retail sales information used for analyzing metrics such as revenue, profit, customers, orders, products, regions, returns, costs, and discounts.

---

## Analysis

### Monthly Business Summary

I started the analysis with a monthly business summary to get an overall view of sales performance.

The analysis includes:

* Revenue
* Orders
* AOV
* Customers
* Return Rate
* Profit
* Cost
* Discount
* Month-over-month percentage changes

This provides a starting point for looking at changes in business performance over time.

### Revenue Analysis

The revenue analysis uses a drill-down approach to look at:

* AOV
* Orders
* Customers
* Return Rate

This gives a more detailed view of revenue performance instead of looking at revenue alone.

### Profit Analysis

The profit analysis looks at profit performance along with:

* Cost
* Discount

These metrics are compared over time to analyze changes in profit performance.

### Customer Analysis

The customer analysis focuses on customer-related performance and changes over time.

### Product Analysis

The product analysis includes:

* Top Products
* Slow Moving Products

This helps compare product performance and identify products performing better or slower.

### Region Analysis

The region analysis compares:

* Best Performing Region
* Worst Performing Region

This provides a regional view of sales performance.
